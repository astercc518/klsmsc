## 一、当出海遇上短信：你正在为"看不见的损耗"买单

短信，是全球用户触达成本最低、覆盖最广、最不依赖网络环境的通道。一条验证码、一条物流通知、一条大促营销——背后都是真金白银的转化。

但当你真正开始做全球生意，会发现"发短信"这件小事，藏着四个让人血压升高的坑：

- **❌ 价格是一笔糊涂账。** 上游报价层层加价，国家与运营商之间差价巨大，月底对账永远对不平，到底亏在哪里？没人说得清。
- **❌ 送达率是一个黑盒。** 钱花出去了，用户没收到。通道一抖动，验证码大面积超时，客诉爆炸，而你连"卡在哪一跳"都查不到。
- **❌ 计费复杂到无法自助。** 长短信怎么拆？多币种怎么结算？不同国家不同运营商单价不同，靠 Excel 人肉算账，根本无法规模化。
- **❌ 对接门槛劝退一切。** SMPP 协议、长连接保活、DLR 回执、各国合规策略……每一项都是一道墙，技术团队从立项到上线动辄数月。

**问题的本质从来不是"短信"，而是你没有一套真正属于自己的、透明可控的通信基础设施。**

## 三、四大核心杀手锏

### 🧠 杀手锏一：智能路由引擎 —— 让每一条短信，都走最聪明的那条路

短信成本与质量，70% 由"选路"决定。考拉出海内置**四种路由策略**，一键切换、自动决策：

| 策略 | 解决什么 | 商业收益 |
|---|---|---|
| **优先级优先** | 核心通道优先跑量 | 保障关键业务稳定 |
| **成本优先** | 自动选最便宜的合规通道 | **直接压低短信成本** |
| **质量优先** | 自动选送达率最高的通道 | **拉高验证码到达率与转化** |
| **负载均衡** | 多通道智能分摊流量 | 避免单点拥塞与限速 |

更关键的是——**自动容灾切换**。主通道一旦异常，系统毫秒级把流量切到备用通道，用户无感、业务不断。

> 💰 **ROI 直击：** 同样的发送量，靠"成本优先 + 质量优先"组合策略，既降本又增效。省下来的每一分通道费，都是净利润。

---

### 💴 杀手锏二：精细化三级计费 —— 行业领先的"颗粒度"，把每一分钱算到底

模糊计费是利润的黑洞。考拉出海做到了**业内领先的三级计费模型**：

> **通道（Channel） × 国家（Country） × 运营商（MCC/MNC）**

- **三维定价**：精确到"哪个通道、发往哪个国家、落在哪个运营商"，单价清清楚楚。
- **长短信自动拆分计费**：超长内容自动按段拆分、按段计费，不多收、不漏算。
- **多币种结算**：原生支持 **USD / CNY / EUR**，跨境业务结算无障碍。
- **多级套餐与差异化资费**：按客户、按通道灵活定价，主账户 + 子账户分权分额。

> 💰 **ROI 直击：** 对集成商而言，这套计费引擎本身就是"印钞机"——你可以基于成本价，对下游客户做差异化加价，**赚取稳定的通道差价**，而且每一笔都对得平、查得清。

### 🌐 杀手锏三：Sender ID 动态合规匹配 —— 一套系统，搞定全球合规这道天堑

各国对发送方标识（Sender ID）的合规要求堪称地狱难度：美国要字母 SID、印度要 DLT 注册、不同国家规则天差地别。做错一步，整批短信被运营商直接拦截。

考拉出海用**4 级优先级智能匹配**把这道墙拆掉：

> **用户指定　＞　专属 Sender ID　＞　通用 Sender ID　＞　系统默认**

系统按场景自动匹配最合适的合规 Sender ID，**完美适配美国字母 SID、印度 DLT 等全球各国合规政策**。该用哪个就用哪个，既保合规、又保送达，让你的技术团队从"研究各国法规"中彻底解放。

> ✅ **价值直击：** 别人还在为单个国家的合规焦头烂额，你已经一套系统覆盖全球——**合规，从此是你的竞争优势，而不是拦路虎。**

漂亮的功能，必须有扛得住的工程底座。考拉出海采用**现代化、全异步、可水平扩展**的技术栈：

| 层 | 技术选型 |

| 后端 | **Python FastAPI**（全异步高并发） |
| SMPP 网关 | **Go 语言独立服务**（长连接 / 心跳保活 / 自动重连） |
