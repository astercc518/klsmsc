# 考拉出海 · 国际短信网关系统 —— 产品功能与购买方案

> 一套面向运营商 / 短信服务商 / 出海企业的多租户国际短信网关平台。
> 支持 SMPP 上游直连、多通道智能路由、客户自助门户、Telegram 商务机器人、完整计费与风控审计。

---

## 一、系统能做什么（一句话版）

**把上游 SMPP/接口通道接进来，按客户、按价格、按国家智能分发短信，客户自助充值发送，平台全程计费、回执、风控、对账。**

---

## 二、核心功能模块

### 1. 短信发送引擎
- **单条发送 / API 发送**：标准 HTTP API + API Key 鉴权，可对接客户自有系统。
- **批量发送**：上传 CSV，自动分片、排队、限速，支持几十万级任务。
- **定时发送**：预约时间自动触发。
- **短信模板**：平台模板 + 客户私有模板，变量替换。
- **短链追踪**：自动生成短链、统计点击、按批次出报表、CSV 导出点击明细。
- **失败重发**：可沿原通道重发，保证落地一致性。

### 2. 多通道与智能路由
- **上游通道接入**：内置 Go 语言 SMPP 网关，长连接、心跳保活、自动重连。
- **供应商管理**：多供应商、多通道并存，按通道编码区分上游归属。
- **智能路由**：按国家/地区、价格、优先级、客户分组自动选路。
- **通道-客户关系绑定**：可指定客户走专属通道。
- **回执处理（DLR）**：SMPP / HTTP 双路回执，实时状态回写、归属过滤防串号。

### 3. 多租户客户体系
- **主账户 + 子账户**：客户可自建子账号，分权分额。
- **API Key 管理**：多 Key、独立限额。
- **套餐 / 资费包**：灵活定价模板，按客户、按通道差异化计费。
- **余额与计费**：实时扣费、余额预警、账单流水。
- **客户自助门户**：充值、发送、报表、API 文档、工单全自助。

### 4. 数据号码业务（增值模块）
- 号码库管理、私有号码库、商品/订单/销售体系，支持号码数据交易场景。

### 5. Telegram 商务机器人
- 商务对接、客户咨询、知识库问答、发送辅助，业务流程在 IM 内闭环。

### 6. 管理后台
- 仪表盘、客户管理、员工与角色（super_admin / admin / staff 三级）、通道管理、供应商管理、业务报表、工单系统、知识库。

### 7. AI 辅助
- 内置 AI 接口，可用于内容辅助、智能问答等。

### 8. 安全与审计（企业级）
- **操作审计**：所有管理端变更全量留痕（操作人、动作、详情）。
- **配置审计**：系统配置改动时间线可追溯。
- **安全日志 + 登录日志**。
- **敏感配置保护**：敏感字段默认锁定，二次确认才可改。
- **JWT + API Key 双鉴权体系**。

## 三、技术架构（给客户技术团队看）

| 层 | 技术 |
|---|---|
| 后端 | Python FastAPI（异步） |
| 任务调度 | Celery + RabbitMQ（多队列：发送/回执/结果/数据/Webhook） |
| 前端 | Vue 3 + Vite（中英双语，响应式） |
| 数据库 | MySQL 8 + ProxySQL 连接池（sms_logs 按月分区，支持亿级） |
| 缓存 | Redis 7 |
| SMPP 网关 | Go 独立服务（高并发长连接） |
| 部署 | Docker Compose 一键编排，全容器化 |

**特点**：全容器化交付、水平可扩展、读写分离、消息队列削峰、关键表分区。单机可起步，支持后续横向扩容。

| 维度 | 方案① 源码出售 | 方案② 部署+永久授权 | 方案③ 部署+1年授权 |

| **源代码** | ✅ 完整拥有，可二次开发 | ❌ 不含源码 | ❌ 不含源码 |
| **使用期限** | 永久 | 永久 | 1 年 |
| **授权绑定** | 无锁（完全自主） | 绑定服务器/域名，永久有效 | 绑定服务器/域名，1 年到期 |
| **二次开发** | ✅ 自由 | ❌ 需由我方进行 | ❌ 需由我方进行 |
| **转售/分发** | 可协商（建议授权约束） | ❌ 不可 | ❌ 不可 |
| **后续升级** | 自行维护（可选签维保） | 视协议（建议另签维保） | 授权期内含安全更新 |

| **适合客户** | 有技术团队、要长期自主可控 | 要长期使用、不碰代码 | 先小成本试跑/短期项目 |
| **价格定位** | 最高（一次性买断核心资产） | 中（买使用权，永久） | 入门（年费，最低门槛） |

> 报价建议：源码 ≫ 永久授权 ＞ 1年授权。1年授权可设计为「年费续费」模式，形成持续收入；到期可平滑升级为永久授权（补差价）。
