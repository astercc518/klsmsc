# SMSCPRO 管理员后台操作手册

> 适用版本：SMSCPRO 国际短信平台（管理员/运营后台）
> 说明：本手册按后台左侧菜单的实际模块编写。每节标注【入口】路径与【截图位置】，请按标记在对应页面截图后插入，再导出 PDF/Word 交付。
> 角色：超级管理员(super_admin) > 管理员(admin) > 员工(staff)。部分模块仅 admin 及以上可见。

---

## 0. 登录与总览

### 0.1 登录后台
【入口】浏览器打开 `https://smscpro.com`（或后台域名）→ 进入登录页。
操作步骤：
1. 输入管理员**用户名**与**密码**。
2. 点击「登录」，进入后台工作台。
3. 忘记密码请联系超级管理员在「系统设置 → 账户管理」中重置。
【截图位置】登录页（输入框 + 登录按钮）。

### 0.2 后台布局
- 左侧：分组菜单（概览 / 短信业务 / 数据业务 / 运营中心 / 系统设置 / 我的账户）。
- 顶部：当前管理员、语言切换、退出。
- 主区：当前模块内容。
【截图位置】登录后整体界面（左侧菜单展开 + 顶部栏 + 工作台）。

### 0.3 工作台（Dashboard）
【入口】概览 → 工作台 `/dashboard`
功能：平台关键指标总览（发送量、成功率、余额、近期趋势等）。
操作：进入后查看各统计卡片与图表；可按时间范围筛选。
【截图位置】工作台全貌（统计卡片 + 趋势图）。

## 1. 客户管理（账户）

> 这是日常最核心的模块：开户、充值、绑定通道、按国家路由与报价。

【入口】运营中心 → 客户管理 `/admin/accounts`

### 1.1 账户列表
功能：查看所有客户账户（账户名、余额、状态、协议、API 凭证等）。
操作：
1. 顶部搜索框按**账户名/ID**筛选；按状态/协议过滤。
2. 列表展示余额、状态（启用/停用）、协议（HTTP/SMPP）。
【截图位置】客户账户列表（含搜索栏与一行账户）。

### 1.2 新建客户账户
操作步骤：
1. 点击右上「**新增账户**」。
2. 填写：账户名、初始密码/API 凭证、协议类型（HTTP / SMPP）、币种、限速(TPS)、状态。
3. 保存后系统生成 API Key（客户对接用）。
【截图位置】新增账户弹窗（表单字段）。

### 1.3 充值/调整余额
操作步骤：
1. 在账户行点「**更多 → 充值**」（或余额操作）。
2. 输入充值金额、备注，确认。
3. 余额即时更新；记录可在「充值记录」查询。
【截图位置】充值弹窗 + 充值后余额变化。

### 1.4 国家路由与报价（重要）
> 控制该客户「发哪个国家、走哪条通道、什么价」。

操作步骤：
1. 账户行点「**更多 → 国家路由与报价**」。
2. 弹窗中按国家添加：选择**国家**（可选「* 全部国家」作兜底）、绑定**通道**（可选「全部通道(*)」）、设置**销售单价**。
3. 留空单价可点「清空」回退默认。
4. 保存。之后该客户发该国短信即按此通道与价格。
【截图位置】国家路由与报价弹窗（一行国家+通道+单价）。

### 1.5 启用/停用、查看 API 凭证
- 停用：账户行「停用」，停用后该客户无法发送。
- 查看 API Key/密钥：账户详情中展示，供客户 API 对接。
【截图位置】账户详情（API 凭证区，注意交付时打码）。

## 3. 通道配置（含国家路由 / SID）

> 短信能否发出、用什么发送方ID，由通道决定。

【入口】运营中心 → 短信业务 → 通道配置 `/channels`

### 3.1 通道列表
列含：通道代码、名称、协议(SMPP/HTTP/VIRTUAL)、服务器地址、账号、通道状态(启用/在线)、速率控制、默认SID、供应商。
行操作：详情、编辑、**路由配置**、价格配置、测试、状态检测、启用/禁用、删除、一键检查。
【截图位置】通道列表（一行通道 + 操作按钮）。

### 3.2 新建/编辑通道
操作步骤：
1. 「新增通道」→ 填：通道代码、名称、协议、服务器地址(SMPP host:port)/API地址、账号密码、默认SID、速率(TPS)。
2. 保存。
【截图位置】通道新增/编辑弹窗。

### 3.3 状态检测 / 一键检查
- 行「**状态检测**」：探测单条通道连通性。
- 顶部「**一键检查**」：批量探测所有通道在线状态。
【截图位置】一键检查结果。

### 3.4 路由配置 + 发送方ID(SID) 管理（新功能）
> 客户发送时可从该通道在某国家配置的多个 SID 中下拉选择。

操作步骤：
1. 通道行点「**路由配置**」。
2. 弹窗为**按国家一行**的路由规则列表。先「**添加路由**」加入目标国家（如巴西），设优先级、启用。
3. 该国家行操作列点「**SID**」→ 打开 SID 管理。
4. 顶部显示国家（只读，如「巴西 (BR)」）→ 点「**添加SID**」。
5. 填：**发送方ID**（如 888001）、类型(字母/数字/短码)、**状态选「启用 active」**、可设**默认**。
6. 可加多个 SID（默认一个，其余备选）。
【截图位置】① 路由配置弹窗（国家列表 + SID 按钮）；② SID 管理弹窗（国家 + SID 列表 + 添加SID）；③ 添加SID 表单。

要点：
- 仅**启用(active)**的 SID 会出现在客户发送页的「发送者ID」下拉。
- 客户发送时（手输号码识别国家 / 私库 / 数据源），系统据通道+目的国家列出可选 SID，未选则用默认SID。

## 6. 短信发送

【入口】短信业务 → 发送 `/sms/send`

### 6.1 单条/手动发送
操作步骤：
1. **收件号码**：手动输入（每行一个，E.164 如 +55119...）。
2. **短信内容**：输入正文，可用变量按钮（序号、号码、国家等）。
3. **发送者ID**：选了通道且识别出目的国家后，此处为**下拉**（该通道该国家可用 SID），选一个；无配置时为自由输入。
4. （多通道账户）选择**通道**。
5. 点「发送」。
【截图位置】发送页（号码框 + 内容框 + 发送者ID下拉 + 通道）。

### 6.2 私库/数据源取号发送
- 切到「**私库**」标签：选库分组、数量，发送（发送者ID 按该库国家出下拉）。
- 切到「**数据库**」标签：选数据产品、数量，发送。
【截图位置】私库取号 + 发送者ID下拉。

### 6.3 模板
【入口】短信业务 → 模板 `/sms/templates`
功能：常用短信文案模板，发送时可套用。
【截图位置】模板列表 + 新建模板。

## 附录 A：常见运营流程速查

| 场景 | 操作路径 |
|---|---|
| 给新客户开户 | 客户管理 → 新增账户 |
| 给客户充值 | 客户管理 → 更多 → 充值 |
| 指定客户某国走哪条通道、什么价 | 客户管理 → 更多 → 国家路由与报价 |
| 给通道某国家配发送方ID(SID) | 通道配置 → 路由配置 → 国家行「SID」 |

| 改 Bot Token | TG机器人 → 机器人配置 → 保存 → 重启Bot |
| 改平台配置 | 系统设置 → 系统配置 → 保存改动（按需重启） |

## 附录 B：发送方ID(SID) 端到端说明
1. 管理员在「通道配置 → 路由配置 → 国家行 SID」为通道+国家配置若干 active SID（设一个默认）。
2. 客户在发送页选该通道、目的国家（手输号码识别 / 私库 / 数据源），「发送者ID」出现可选 SID 下拉。
3. 客户选定后发送，系统以所选 SID 作为该批短信的发送方；未选则用默认 SID，无配置则用通道默认 SID。
4. 仅 active 的 SID 生效；非法 SID 在发送时被白名单拦截。

## C.2 新建通道
1. 点列表右上「新增通道」。

## C.4 配置发送方ID(SID)——核心
> 目标：让客户发某国短信时，能从该通道为该国配置的多个 SID 中下拉选择。

### 步骤 1：先给通道加该国家的「路由」
1. 通道行点「**路由配置**」。
2. 弹窗为「按国家一行」的路由规则表：
```
路由配置 - MM通信直连
┌──────────┬────────┬──────┬────────┬───────────┬──────────────────┐
│ 国家     │ 优先级 │ 启用 │ 违禁词 │ 更新时间  │ 操作             │
├──────────┼────────┼──────┼────────┼───────────┼──────────────────┤
│ 巴西(BR) │   0    │  是  │   -    │ ...       │ 编辑  SID  删除  │
└──────────┴────────┴──────┴────────┴───────────┴──────────────────┘
[ + 添加路由 ]
```
3. 若没有目标国家，先点「**添加路由**」→ 选国家（如巴西）→ 设优先级、启用 → 保存。
【截图位置】路由配置弹窗（含国家行与「SID」按钮）。

### 步骤 2：在该国家行配置 SID
1. 目标国家行点「**SID**」→ 打开 SID 管理：
```
发送方ID(SID)管理 - MM通信直连
国家：[巴西 (BR)]        [ + 添加SID ]   （仅"启用active"的SID会出现在客户发送页下拉）
┌────────────┬────────┬────────┬──────┬──────────────┐
│ 发送方ID   │ 类型   │ 状态   │ 默认 │ 操作         │
├────────────┼────────┼────────┼──────┼──────────────┤
│ 888001     │ 数字   │ active │ 是   │ 编辑  删除   │
│ 888002     │ 数字   │ active │ -    │ 编辑  删除   │
│ 888003     │ 数字   │ active │ -    │ 编辑  删除   │
└────────────┴────────┴────────┴──────┴──────────────┘
```
2. 点「**添加SID**」，在弹窗填写：

| 字段 | 说明 |
|---|---|
| 发送方ID | SID 内容，如 `888001` |
| 类型 | 字母 alpha / 数字 numeric / 短码 shortcode |
| 状态 | **启用 active**（必须，否则不进客户下拉） |
| 设为默认 | 开启则客户不选时默认用它（每国家一个默认） |

3. 保存。可重复添加多个（一个默认 + 若干备选）。
【截图位置】① SID 管理弹窗；② 添加SID 表单。

### 步骤 3：客户端效果
客户在「短信发送」页：选该通道、目的国家（手输号码自动识别 / 私库 / 数据源），「发送者ID」字段变为**下拉**，列出这些 SID（默认项已选中）。客户选定后该批短信即用所选 SID 发出。
- 未选 → 用该国默认 SID；无国家级 SID → 用通道「默认SID」。
- 仅 active 生效；非法 SID 发送时被白名单拦截。
【截图位置】客户发送页「发送者ID」下拉展开。

### 常见问题
- 「通道未支持该国家，请先在路由配置为该国家添加路由」：先在步骤 1 给该通道加该国家路由。
- 客户发送页无 SID 下拉：确认①该国 SID 为 active；②客户确实选了该通道；③已识别出目的国家（手输需带国码、私库/数据源选了对应国家库/产品）。

# 附录 D：TG 业务助手开户流程详解

> 「业务助手」即平台 Telegram 机器人。开户分**授权码开户**（推荐，销售发码）与**业务工单开户**（自助提交需求）两种；最终都由管理员在后台完成开账户。

## D.1 流程总览
```
 销售/管理员                客户(TG)                     管理员后台
 ───────────              ──────────                   ────────────
 创建开户邀请  ──授权码──►  输入授权码开户  ──►自动注册/绑定TG──► 客户管理可见新账户
   (邀请码)                                              ↓
                          或: 业务菜单→短信开户         开户工单
                              →填需求描述  ──建工单──►  工单管理(处理/开户/回复)
```

## D.2 方式一：授权码开户（销售发码）
管理员/销售侧：
1. TG 业务助手菜单点「🎯 创建开户邀请」；或后台「TG机器人 → 邀请码」生成。
2. 系统生成**授权码（邀请码）**，把它发给客户。
【截图位置】创建开户邀请界面 + 生成的授权码。

客户侧（TG）：
1. 打开业务助手 → 游客菜单点「🔑 输入授权码开户」。
2. 粘贴授权码 → 按提示完成（自动注册并绑定其 Telegram）。
3. 成功后进入客户菜单，可发短信/查余额。
【截图位置】客户输入授权码 + 开户成功提示。

管理员侧确认：
- 后台「客户管理」中出现该新账户；按需充值、配「国家路由与报价」。
- 「TG机器人 → 邀请码」可查邀请码使用状态。

## D.3 方式二：业务工单开户（自助）
客户侧（TG）：
1. 业务助手菜单 → 选业务「📱 短信 SMS」。
2. 点「🏢 短信开户」。
3. 按提示**输入需求描述**（5–2000 字，如公司、用途、目标国家、预计量）。
4. 提交 → 生成**开户工单**并推送到技术群。
【截图位置】短信开户业务菜单 + 需求描述输入 + 提交成功。

管理员侧：
1. 后台「运营中心 → 工单管理」看到该开户工单（类型=开户/registration）。
2. 打开工单 → 与客户沟通/回复 → 在「客户管理」新建账户、充值、配通道路由与报价。
3. 把账户凭证/授权码反馈给客户，关闭工单。
【截图位置】工单管理列表（开户工单）+ 工单详情/回复。

## D.4 （语音/数据）带模板定价的开户
> 若平台开通语音/数据业务，开户流程更细（SMS 走上面的工单式）：
- 选业务（语音/数据）→ 选国家 → 选线路/模板 → **逐条设卖价（须 ≥ 底价×1.1）** → 确认 → 发技术群 + 建工单。
- 底价来源：供应商成本价（见「供应商报价/开户模板」）。
【截图位置】（如适用）选模板 + 设卖价 + 确认开户信息。

## D.5 开户后必做（管理员）
| 步骤 | 路径 |
|---|---|
| 新建/确认账户 | 客户管理 → 新增账户 / 工单转化 |
| 充值 | 客户管理 → 更多 → 充值 |
| 配国家路由与报价 | 客户管理 → 更多 → 国家路由与报价 |
| 配该国发送方ID | 通道配置 → 路由配置 → 国家行 SID（附录C） |
| 给客户 API 凭证（如走API） | 账户详情查看 API Key |

## D.6 Bot 配置前提（运维）
- 「TG机器人 → 机器人配置」需正确填 **Bot Token**；改 Token 后点「**重启 Bot**」生效。
- 开户模板/国家由「开户模板」「供应商报价」维护；国家中文名为单一数据源，加国家只改一处。
【截图位置】机器人配置（Token + 重启Bot）。
